# نجوم الملعب — النموذج الأولي 3D

هذا مشروع بداية قابل للتطوير باستخدام **Godot 4.x**. يتضمن ملعبًا ثلاثي الأبعاد، لاعبين تجريبيين، كرة فيزيائية، مرميين، خصمًا يتحرك نحو الكرة، أزرار لمس، وتسديدًا وتمريرًا.

## ما تحتاجه
- Godot Engine 4.3 أو إصدار 4.x حديث.
- Android SDK وJava JDK عند تجهيز تصدير Android.
- مساحة كافية لتثبيت قوالب التصدير Export Templates.

## تشغيل المشروع على الكمبيوتر
1. فك ضغط `Nujoom_AlMalaeb_Godot.zip`.
2. افتح Godot Project Manager.
3. اختر **Import** وحدد ملف `project.godot`.
4. افتح المشروع واضغط **F6** أو زر التشغيل ▶.
5. على الكمبيوتر: استخدم WASD أو الأسهم، وجرّب أزرار التسديد والتمرير.

## بناء APK حقيقي للأندرويد
1. نزّل Godot 4.x من الموقع الرسمي وثبّت **Export Templates** من قائمة Editor.
2. ثبّت Android Studio، ومن SDK Manager ثبّت Android SDK Platform وBuild-Tools وCommand-line Tools.
3. في Godot افتح **Editor > Editor Settings > Export > Android**، واضبط مسارات Android SDK وJava SDK حسب جهازك.
4. افتح **Project > Export** ثم **Add… > Android**.
5. اضبط Package/Unique Name مثل `com.example.nujoomalmalaeb`، وأضف أيقونة إن أردت.
6. اضغط **Export Project** واحفظ الملف باسم `NujoomAlMalaeb.apk`.
7. للتثبيت على هاتفك: انقل APK إلى الهاتف وافتحه، واسمح بالتثبيت من هذا المصدر عند طلب النظام.

> ملاحظة: ملفات المشروع هذه هي نموذج أولي، وليست لعبة تجارية مكتملة. قد تحتاج إعدادات تصدير Android إلى ضبط بحسب نظامك وإصدار Godot. لا يتضمن المشروع شعارات أندية أو لاعبين مرخّصين؛ الألوان واللاعبون تجريبيون.

## عناصر التحكم
- الأسهم أو WASD على الكمبيوتر.
- أزرار الاتجاهات على الشاشة في الهاتف.
- **تسديد**: تسديد قوي إذا كنت قريبًا من الكرة.
- **تمرير**: دفع الكرة بقوة أقل.

## المرحلة التالية المقترحة
- استبدال المجسمات البسيطة بنماذج شخصيات ثلاثية الأبعاد مرخّصة.
- إضافة هيكل عظمي وAnimationTree لحركات الجري والتسديد والاحتفال.
- إضافة اختيار الأندية، قائمة البداية، مؤقت المباراة، وحارس مرمى.
- تحسين تحكم اللمس، الذكاء الاصطناعي، والصوتيات قبل نشر اللعبة.
